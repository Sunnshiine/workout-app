## How to read the GitHub record

- Every July comment under the Sunnshiine account carries a "_Generated by Claude Code_" footer.
  The deck quotes them as **the agent's record of my verdict**, not as words the owner typed. The
  owner's typed feedback lived in the cloud sessions.
- Workflows ran under `AGENT_PAT`, so bot relabels and PRs show the actor Sunnshiine. Chain steps
  are told apart by timing: each relabel lands seconds after the previous run ends.
- Commit model trailers are unreliable (970296cb says Opus 4.8 after #510 set Opus 5). The deck
  names no model for any run.
